Stream API 🧮

Добавим в наше приложение статистику в виде отдельной CLI команды. Нужно реализовать несколько статистических запросов.
Вакансии с опытом не менее указанного.
stat --exp 5
Список юзеров, у которых есть больше или равно чем N мэтчей.
stat --match 2
Топ N скиллов среди всех пользователей (скиллы, которые чаще всего встречаются).
stat --top-skills 3
Формат входных данных
На вход подаются доступные CLI команды, среди которых будет команда `stat`.
Формат выходных данных
В ответ на команду
stat --exp <n>
необходимо вывести список подходящих вакансий в алфавитном порядке в том же формате, что и job-list.
В ответ на команду
stat --match <n>
необходимо вывести список подходящих юзеров в алфавитном порядке в том же формате, что и user-list.
В ответ на команду
stat --top-skills <n>
необходимо вывести список скиллов в алфавитном порядке, каждый с новой строки.
Замечание
При реализации такой статистики приветствуется активное использование Stream API.
