Добавляем работу с файлами 📂
Чтобы вручную не вводить постоянно команды по добавлению юзера и тд, нужно сохранять каждую команду в текстовый файл.
При старте приложения, пытаться считать команды из файла и выполнить их одна за другой.
Сохранять в файл нужно все команды, а выполнять при запуске только те, которые создают сущности (добавление юзера и добавление вакансии).
Логику работы с файлами постараться вынести в отдельный класс. Например FileService, в котором будет 2 публичных метода: 1) сохранить (залогировать) только что выполненную команду, 2) получить список комманд, введенных ранее.
В CLI интерфейс добавить команду history, которая выведет список ранее введенных команд из файла.
Важное замечание:
Каждая введенная команда сначала выполняет то, для чего она предназначена, а потом записывается в файл. Таким образом команда exit в файл записываться не будет.
Формат входных данных
На вход подается набор доступных CLI команд. Одна из команд — команда history
Формат выходных данных
В ответ на команду history выводится список команд, введенных ранее. Каждая с новой строки.
