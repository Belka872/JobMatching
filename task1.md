Будем разрабатывать простой симулятор системы рекомендаций вакансий — Job Recommender.
В системе можно создать профиль пользователя (опыт, технологии, интересы) и вакансии (теги, описание). На основе совпадений, система предлагает наиболее релевантные вакансии для пользователей.

На первом этапе необходимо создать скелет работающего приложение. Создать сущности, с которыми будем работать. А также простой CLI (Command Line Interface) интерфейс для работы с ними. Названия сущностей, их набор можете называть по своему. Ниже пример:
Создать основные классы:
для пользователя системы (имя, список навыков, опыт)
для вакансий, которые будут публиковаться в системе (название, компания, теги, требуемый опыт)
для мэтча между пользователем и вакансией (результат сопоставления — насколько мэтчится пользователь с вакансией)
Реализовать CLI-команды:
user <name> --skills=... --exp=.... Добавляет пользователя в систему. Например:
user alice --skills=java,ml,linux --exp=2
user-list — выводит список пользователей (каждого с новой строки) в формате:
Alice java,ml,linux 2
Bob c++,python 5
job <title> --company=... --tags=... --exp=... Добавляет вакансию. Например:
job Backend_Dev --company=VK --tags=java,backend,linux --exp=1
job-list — выводит список вакансий (каждую с новой строки) в формате:
Backend_Dev at VK
Java_developer at Google
suggest <username> — выводит не больше 2 вакансий, подходящих указанному пользователю. Степень того, насколько подходит вакансия предлагается вычислять как количество совпадений между skills юзера и tags вакансии. Если опыта (exp) у юзера не хватает, то поделить полученное количество пополам.
exit — завершает работу приложения с кодом 0. System.exit(0);
Хранить данные в памяти
Для реализации CLI используйте java.util.Scanner
Формат входных данных
На вход подается любой набор CLI команд из описания. Например:
user alice --skills=java,ml,linux --exp=2
Список параметров команды не сортирован
user bob --exp=10 --skills=java,java,java
Каждый набор входных данных заканчивается командой exit.
Формат выходных данных
Выходные данные в ответ на команду user-list — в формате <name> <skills> <exp>
alice java,ml,linux 2
Выходные данные в ответ на команду job-list — в формате <job_title> at <company>
Backend_Dev at VK
Java_developer at Google
Формат выходных данных в ответ на команду suggest такой же, как и на команду job-list
Пример 1
Входные данные

user alice --skills=java,ml,linux --exp=2
user bob --skills=java,java,java --exp=10
user-list
exit
Выходные данные

alice java,linux,ml 2
bob java 10
Замечание
Старайтесь реализовывать функционал по принципу Tell Don't Ask (из лекции).
Понятная структура программы, названия переменных, методов вам самим поможет дальше работать с программой.
Повторное создание юзера с тем же именем, или вакансии с тем же названием не должно приводить к перезаписи ранее созданной сущности.
Не стоит выводить в консоль посторонние символы. Это может помешать автоматической проверке.
